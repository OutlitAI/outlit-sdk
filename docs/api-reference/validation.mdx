---
title: "Validate an API key"
description: "Verify that an Outlit API key can authenticate Platform API requests."
openapi: "openapi.json POST /api/validate-api-key"
---

## Authentication

Pass an Outlit API key in the `Authorization` header as `Bearer ok_...`.

## Request body

No request body is required when validating the API key from the `Authorization` header.

## Example

```bash
curl -X POST https://app.outlit.ai/api/validate-api-key \
  -H "Authorization: Bearer ok_your_api_key"
```

## Success response

```json
{
  "valid": true,
  "organizationId": "org_123",
  "createdById": "user_123",
  "authorization": {
    "grants": ["customer_intelligence:read"]
  }
}
```

`authorization.grants` lists the key's current capabilities. Only offer commands whose required
authority appears in this list. `createdById` is null when the creator is unavailable.

## Error responses

Invalid or disabled keys return `401`:

```json
{
  "valid": false,
  "error": "Invalid credentials"
}
```

If the credential store is temporarily unavailable, the endpoint returns `503` with the same
failure envelope. Retry that response; it does not mean the key is invalid or revoked.
