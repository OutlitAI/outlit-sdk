title: "Workspace configuration"
description: "Manage safe destinations, activation, workspace settings, and Features through the tool gateway."
---

Use `POST /api/tools/call` or the CLI to manage delivery destinations, the activation event, selected workspace settings, Features, and integration setup. Each action requires the matching API-key grant or member permission.

## What you can configure

| Area | Tools |
|------|-------|
| Destinations | List, get, create, update, enable, disable, and archive |
| Activation | Get, preview, and update the ordinary customer activation event |
| Workspace settings | Get and update the workspace timezone |
| Features | List, create, and archive product capabilities observed through exact event rules |
| Integrations | List integrations, complete supported setup steps, and check readiness |

Destination results mask configuration values. Integration setup accepts provider-specific credential and configuration shapes and does not return submitted credentials. See [Agents and AI overview](/ai-integrations/overview#read-vs-write-controls) for public tool boundaries.

For example, use these CLI commands to perform the same actions:

```bash
outlit destinations create --type slack --channel-id C0123456789 --label "#customer-ops" --default --json
outlit activation preview --event activated --json
outlit settings update --default-timezone America/Los_Angeles --json
outlit features list --json
outlit features create --source metric_source_v1_0123456789abcdef0123456789abcdef --event report_exported --key reports_exported --name "Reports exported" --json
outlit features archive value_feature_v1_0123456789abcdef0123456789abcdef --revision value_feature_revision_v1_fedcba9876543210fedcba9876543210 --json
```

Use the generated [OpenAPI specification](/openapi.json) for the exact request, output, and stable gateway error schemas.
