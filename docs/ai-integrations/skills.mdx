Agent skills teach coding agents how to work with Outlit. The `outlit` skill covers customer intelligence workflows. The optional `outlit-sdk` skill covers tracking and instrumentation work.

Skills are open source at [github.com/OutlitAI/skills](https://github.com/OutlitAI/skills).

Use skills when the agent runs local commands or needs workflow guidance. Use [MCP integration](/ai-integrations/mcp) for remote MCP clients, and use [Pi agents](/ai-integrations/pi) when you are packaging a Pi extension with Outlit tools, prompts, or custom skills.

## Give your agent the skill

The `outlit` skill ships with every Outlit interface, so an agent can read it without installing anything.

**CLI.** Tell your agent to run:

```bash
outlit --skill
```

It prints the full skill to stdout. It needs no API key and no network, and it always matches the installed CLI version, so there is nothing to keep up to date.

**MCP or the tool gateway API.** Have your agent call `outlit_get_skill` once at the start of a session. It takes no input and returns the same skill text. It's in the `meta` toolset, which the default MCP URL (`?toolsets=core,work,meta`) loads. The skill is about 20 KB (5,000 tokens), and every call returns the same text, so one read per session is enough.

## Install a skill stub (optional)

To have agents discover Outlit on their own, install a small `outlit` skill that tells the agent to run `outlit --skill`:

```bash
outlit setup --yes
```

This detects installed agents. To choose agents manually, run `outlit setup skills`. For a specific agent, use `outlit setup <agent>`; [Set up coding agents](/cli/ai-agents#supported-agents) lists the supported names. The installed stub never goes stale, because the instructions come from `outlit --skill` at run time.

<Accordion title="Install the optional outlit-sdk skill">

The `outlit-sdk` tracking skill is not part of the CLI. Install it with the skills installer:

```bash
npx -y skills add OutlitAI/skills --skill outlit-sdk -g
```

</Accordion>

## Verify

```bash
outlit doctor
```

Look for a per-agent check such as:

```text
✓ Claude Code: Outlit skill installed
```

## Available skills

| Skill | What it teaches |
|-------|-----------------|
| **outlit** | Customer queries, timelines, search, facts, SQL, and when to use CLI vs MCP |
| **outlit-sdk** | Tracking integration work: detection, consent, authentication, billing-integration guidance, and event instrumentation |
